- 👋 Hi, I’m @BjornTheProgrammer
- 👀 I’m interested in developer tools, embedded software, and web libraries.
- 🦀 Lately I've been working mostly in Rust, from microcontroller tooling to web backends. 

### What I'm working on

- **[elf2flash](https://github.com/BjornTheProgrammer/elf2flash)**: A Rust tool for flashing ELF files to microcontrollers, plus two published crates for talking to USB mass-storage devices directly over SCSI and FAT, with no OS mounting required.
- **[bun-plugin-html](https://github.com/BjornTheProgrammer/bun-plugin-html)**: A plugin that lets `bun build` use HTML files as entrypoints, maintained with contributions from the community.
- **[logto-sdk](https://github.com/BjornTheProgrammer/logto-sdk)**: An unofficial Logto authentication SDK for Rust with support for axum, actix, and rocket.
- **[vue-simple-phone](https://github.com/BjornTheProgrammer/vue-simple-phone)**: A multilingual, extendable phone number input component for Vue.
